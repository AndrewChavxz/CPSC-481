## Dependencies
- Python
- Pygame

The only external dependency you need to install is pygame. The sys module is part of the Python standard library and comes built-in.

Install Pygame:
Open your terminal (or Command Prompt / PowerShell) and run:
```
# pip install pygame
```

## How to Play/Run:
Once pygame is installed, you can start the game by executing the Python file. Run:
```
# python main.py
```
(Make sure you are in the directory where main.py is saved when you run the command!)

The game window should display and you can start playing.
