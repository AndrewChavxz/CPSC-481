We assume you have python already
To run this game, the only external dependency you need to install is pygame. The sys module is part of the Python standard library and comes built-in.

Here is exactly what you need to do to run it:

Install Pygame:
Open your terminal (or Command Prompt / PowerShell) and run:
pip install pygame

Run the Game: 
Once pygame is installed, you can start the game by executing the Python file. Run:
python main.py (Make sure you are in the directory where main.py is saved when you run the command!)

The game window should pop up and you can start playing.
